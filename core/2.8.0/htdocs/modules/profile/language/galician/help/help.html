DESCRICIÓN

O módulo Perfil é para xestionar campos de perfil de usuario personalizados.

INSTALAR/DESINSTALAR

Non se necesitan medidas especiais, siga o proceso de instalación estándar: extrae o cartafol /profile no directorio ../modules. Instale o módulo a través de Admin -> System Module -> Modules.

Existen instrucións detalladas sobre a instalación de módulos na páxina XOOPS Manual de operacións

INSTRUCIÓNS DE FUNCIONAMENTO

Para configurar este módulo necesitas:

  • Configure as súas preferencias para o módulo (consulte ‘Preferencias’) e, opcionalmente, o bloque Perfil se quere usalo (consulte ‘Bloques’).
  • Edita as categorías existentes ou engade outras novas.
  • Edita os campos existentes ou engade outros novos. Aquí podes especificar que campos serán visibles en que categoría e se estarán visibles durante o rexistro do usuario.
  • Defina a orde dos pasos de rexistro.
  • E, finalmente, pode establecer permisos para campos individuais: cales son editables e cales poden buscar.

Medidas anti-spam

Para minimizar os rexistros de spam, faga o seguinte:

  • vai ao módulo Protector en Administración, vai a Preferencias e, a continuación, na parte inferior, nesta opción: "Deter spam do foro" Comproba os datos POST con spammers rexistrados na base de datos www.stopforumspam.com.
    Establéceo como "Prohibir a IP (sen límite)"

  • en /class/captcha/config.php, asegúrate de que o modo estea definido como "texto":

    devolve $config = matriz(
    'disabled' => falso, // Desactiva CAPTCHA
    'mode' => 'texto', // modo predeterminado, podes escoller 'texto', 'imaxe', 'recaptcha' (require chave API)
    'name' => 'xoopscaptcha', // nome captcha
    'skipmember' => verdadeiro, // Saltar a comprobación CAPTCHA dos membros
    'maxattempts' => 10, // Número máximo de intentos para cada sesión
    );

  • No módulo Perfil, vai a Admin e no paso Básico situado en:
    /modules/profile/admin/step.php?id=1
    establece "Gardar despois de parar" en "Non"


  • En Preferencias do perfil, configure a opción "Usar Captcha despois do segundo paso de rexistro" en "Si" (é o predeterminado)
