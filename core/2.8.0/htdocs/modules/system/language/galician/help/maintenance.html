Axuda: Mantemento

Descrición

O mantemento ofrece varias funcións básicas para axudarche a manter a túa instalación XOOPS e mantela sa:

- limpar o cartafol da caché
- baleira a táboa da sesión
- realizar o mantemento das táboas da base de datos (analizar, comprobar, optimizar e reparar)

Tamén pode realizar un "Volcado" de toda a base de datos ou de táboas individuais con fins de copia de seguridade.
