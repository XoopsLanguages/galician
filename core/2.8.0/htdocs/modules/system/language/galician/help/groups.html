Axuda: Grupos

Descrición

XOOPS incorpora un sistema de rexistro de membros - opcionalmente podes esixir que as persoas se rexistren no teu sitio para ter acceso a determinadas áreas ou funcións. Por exemplo, a maioría dos sitios requiren que a xente se una antes de que se lles permita contribuír con noticias ou publicar mensaxes nos foros.
Os dereitos de acceso e administración a un sitio web de XOOPS establécense mediante un sistema de permisos flexible baseado en "grupos de usuarios". Os grupos predeterminados inclúen usuarios anónimos, membros rexistrados e administradores web, pero por suposto podes definir tantos grupos como necesites para xestionar o teu sitio. Cada grupo pode recibir un conxunto único de dereitos de acceso que rexen:

- Que bloques se poden ver
- A que módulos se pode acceder
- Que módulos se poden administrar
- Que aspectos da administración do sistema se poden modificar

Podes cambiar o nome destes grupos predeterminados, pero non podes eliminalos. Tamén se poden configurar e definir outros grupos de usuarios como se comenta máis adiante.

Tamén se poden crear grupos personalizados a través da páxina de administración de grupos.
