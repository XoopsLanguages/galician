Instalando XOOPS

Instalación por primeira vez

Prólogo:

XOOPS é un código aberto Sistema de publicación web orientado a obxectos escrito en PHP. É unha ferramenta ideal para desenvolvendo sitios web comunitarios dinámicos de pequeno a grande, portais intra empresa, portais corporativos, weblogs e moito máis.

XOOPS publícase baixo os termos do Licenza pública xeral GNU (GPL) versión 2 ou superior, e é gratuíto para usar e modificar. É gratuíto a redistribución sempre que cumpra os termos de distribución da GPL.

Requisitos

  • Servidor WWW (Apache, NGINX, IIS, etc.)
  • PHP 8.2 ou superior, recoméndase 8.4+
  • MySQL 5.7 .8 ou superior, recoméndase MySQL 8.4.5+

Antes de instalar

  1. Configure correctamente o servidor WWW, PHP e o servidor de base de datos.
  2. Prepare unha base de datos para o seu sitio XOOPS.
  3. Prepare a conta de usuario e conceda ao usuario o acceso á base de datos.
  4. Fai que os directorios e os ficheiros sexan escribibles: %s
  5. Por consideracións de seguridade, recoméndase encarecidamente que mova os dous directorios seguintes fóra de raíz do documento e cambia os nomes dos cartafoles: %s
  6. Crear (se aínda non está presente) e facer que os directorios sexan escribibles: %s
  7. Activa as cookies e JavaScript do teu navegador.

Instalando localmente

Se estás executando un ambiente local para o desenvolvemento ou probas, asegúrate de ter o anterior requisitos cumpridos. Unha vez feito isto, copie o contido do ficheiro htdocs estado directorio (do XOOPS ficheiro de distribución) á ruta do documento raíz do seu contorno web. Unha vez que se copien alí os ficheiros, pode iniciar a instalación apuntando o seu navegador a "http://yoursite.com". Isto iniciará o proceso de instalación.

Instalando nunha plataforma aloxada

Se está a executar nun ambiente aloxado, desempaquete os ficheiros XOOPS localmente ou no servidor se ten acceso shell (é dicir, SSH). Unha vez feito isto, asegúrate de mover ou copiar todos os ficheiros XOOPS do ficheiro htdocs estado ao teu directorio web raíz (o teu provedor adoita proporcionar indicacións para esta localización). Unha vez que se copien alí os ficheiros, pode iniciar a instalación indicando o seu navegador "http://yoursite.com". Isto iniciará o proceso de instalación.

Continuando coa instalación

Só ten que seguir as instrucións paso a paso no instalador.
