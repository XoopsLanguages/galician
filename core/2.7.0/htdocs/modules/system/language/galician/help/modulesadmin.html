Axuda: Módulos

Descrición

Os módulos son as construcións de software que, aproveitando a infraestrutura que proporciona XOOPS, permiten que o webmaster ofreza aos usuarios do sitio contido dinámico ou estático xerado mediante unha interface web que máis veces non é moi doada de usar.

Parte do poder de XOOPS reside na forma en que se xestionan os módulos. O administrador web pode facilmente instalar, desinstalar, activar ou desactivar calquera módulo específico (excepto o módulo Sistema, por razóns obvias). Tamén é posible cambiar o nome dos módulos e determinar a orde na que se farán aparecen ao usuario final no menú do sitio (se queres que aparezan), porque tamén podes proporcionar funcionalidades ocultas, definindo módulos activos que non teñen presenza visible para o usuario ocasional. Por exemplo, pode definir un módulo como non visible no menú desactivando o icona de verificación na columna Menú. Polo tanto, para o módulo de Noticias, pode enviar mensaxes privadas ao grupo seleccionado dos seus usuarios e dicirlles que accedan a ese directorio escribindo o enderezo no campo URL, algo así. http://www.yoursite.com/modules/news.

Para cambiar a orde dos módulos (que se reflectirá no Menú), só tes que arrastrar e soltar os módulos ata a ubicación desexada.

A instalación dos módulos necesita algunha planificación, tanto para os módulos que se van mostrar como para o deseño das páxinas. É unha boa idea revisar outros sitios XOOPS e ver que módulos se usan para mostrar varios tipos de contido. Isto faise facilmente abrindo calquera sitio XOOPS e pasando o rato por riba as ligazóns do menú nos paneis laterais esquerdo e dereito. Ao mesmo tempo, mira os URL que aparecen na barra de estado do teu navegador. Debería ver enderezos como este: http://the_site.com/modules/news/.... Todos os módulos están almacenados no directorio /modules/, polo que o seguinte sector do enderezo (neste exemplo 'noticias') mostra o módulo que mostrará o contido desa ligazón de menú.

Se abres a páxina da ligazón mostrarase un exemplo de como se usa o módulo e o tipo de contido que mostra. Revisar outros sitios como este tamén che dará unha boa visión das capacidades de deseño e deseño.
