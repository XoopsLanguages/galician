DESCRICIÓN

O módulo PM é para mensaxes privadas entre usuarios

INSTALAR/DESINSTALAR

Non se necesitan medidas especiais, siga o proceso de instalación estándar: extrae o cartafol /pm no directorio ../modules. Instala o módulo a través de Admin -> System Module -> Modules. Ligazón

Existen instrucións detalladas sobre a instalación de módulos na páxina Operacións XOOPS Manual

INSTRUCIÓNS DE FUNCIONAMENTO

Para configurar este módulo necesitas:

  • Introduce a súa caixa de entrada directamente desde a páxina principal, ou premendo na ligazón superior "Ir ao módulo" na área de administración do PM.
  • Configure as súas preferencias para o módulo (consulte "Preferencias") e, opcionalmente, o bloque PM se pretende usalo (consulte "Bloques").
  • Podes eliminar en masa as túas mensaxes usando a pestana "Podar" Mensaxes".
